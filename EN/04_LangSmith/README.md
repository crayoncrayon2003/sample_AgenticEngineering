# 04_LangSmith

This folder contains no examples.

## Reason

LangSmith is a tracing and evaluation service from the developers of LangChain.

LangSmith cannot run solely on a local PC for the following reasons.

- Only the paid Enterprise edition supports local operation.
- The cloud edition has a free plan, but requires an account and API key.

Without an API key, evaluation and prompt management fail, and traces are not recorded.

No examples are provided because their operation could not be verified.

## Alternative

You can try similar features with [05_Langfuse](../05_Langfuse/README.md).
