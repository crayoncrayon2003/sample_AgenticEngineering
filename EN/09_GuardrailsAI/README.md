# 09_GuardrailsAI

Examples of Guardrails AI, a library that validates LLM output using validators and Pydantic classes.

The inspection parts of the 01_LangChain examples are replaced with Guardrails AI.

Compare files with the same number in 01_LangChain and 09_GuardrailsAI to see the differences.

## Setup

Run these examples in a dedicated virtual environment rather than the root `.venv`.

Guardrails AI requires openai package 2.x, which cannot coexist with openai 3.x in the root environment.

Install packages from this folder's `requirements.txt` in the dedicated environment (the root `requirements.txt` does not include Guardrails AI).

```bash
cp 09_GuardrailsAI/.env.example 09_GuardrailsAI/.env
```

| Variable | Required | Description |
| ---- | :--: | ---- |
| `LLM_PROVIDER` | | LLM provider: `openai` or `anthropic`. Defaults to `openai` |
| `OPENAI_API_KEY` | When using OpenAI | OpenAI API key |
| `OPENAI_MODEL` | | OpenAI model. Defaults to `gpt-5-nano` |
| `ANTHROPIC_API_KEY` | When using Claude | Anthropic API key |
| `ANTHROPIC_MODEL` | | Claude model. Defaults to `claude-haiku-5-5` |

Each file disables Guardrails AI usage telemetry (see "Usage telemetry" below).

## LLM used for inspection

Guardrails AI can also call LLMs through Guard to inspect and correct output.

03_02_OutputCheck.py and 03_03_SchemaCheck.py only use Guard to inspect output generated by LangChain chains. Custom validators and Pydantic classes perform the checks without an LLM.

Guardrails Hub, a service distributing ready-made validators, is not used. All validators are custom, so no Hub registration or token is needed.

## Usage telemetry

Without a configuration file (`~/.guardrailsrc`), Guardrails AI sends usage information to an internet server.

Each file disables transmission in two places.

- `settings.rc.enable_metrics = False`: Set before creating validators, which use settings from creation time.
- `guard.configure(allow_metrics_collection=False)`: Set for each Guard, which rereads the configuration file during creation.

You can also use `guardrails configure` to disable transmission in the configuration file.

## Notes

- A nonexistent date such as `1995-02-30` in `03_03_SchemaCheck.py` has the correct YYYY-MM-DD format, so the Pydantic class constraints alone cannot detect it. A custom validator checks this.

## Differences between NeMo Guardrails and Guardrails AI

The two are similar for checking LLM inputs and outputs, but have different origins and goals.

* NeMo Guardrails: Originates from conversation control. YAML-configured rails govern input, output, and dialogue flow.
* Guardrails AI: Originates from output validation. Combines validators to check output structure and content.
