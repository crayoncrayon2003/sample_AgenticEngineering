# 04_LangSmith

このフォルダには、サンプルを置いていません。

## 理由

LangSmith は、LangChain の開発元が提供するトレース・評価のサービスです。

LangSmith は、 ローカルPC だけで動きません。理由は、以下です。

- 有料の Enterprise 版 のみ、ローカルPC で動かすことができる。
- クラウド版には、無料プランがある。ただし、アカウントの登録と API キー の取得が必要

API キー が無い状態では、評価やプロンプト管理はエラーになります。トレースは記録されません。

動作を確かめられないため、サンプルは作っていません。

## 代わりに

同様の機能は、[05_Langfuse](../05_Langfuse/README.md)で試すことが可能です。
